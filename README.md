
# FARMCONNECT
## A Digital Agricultural Marketplace

### 1. Project Overview

FarmConnect is a web-based agricultural marketplace designed to connect farmers directly with buyers. The platform allows farmers to showcase and sell their agricultural products while enabling buyers to discover and purchase fresh farm produce conveniently.

The main goal of FarmConnect is to simplify agricultural trading, improve access to markets, and create a direct connection between farmers and consumers.

### 2. Main Features

#### User Registration and Login
- Users can create accounts and log in securely.
- The platform supports two user roles: Farmers and Buyers.
- Users access features according to their account roles.

#### Farmer Features
- Add agricultural products to the marketplace.
- Manage their listed products.
- View orders placed by buyers.
- Accept or reject incoming orders.
- Mark accepted orders as completed.

#### Buyer Features
- Browse available agricultural products.
- Search for products by name, category, or location.
- View product details, prices, and availability.
- Add products to a shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- Proceed to checkout.
- View order history and cancel pending orders.

#### Order Management
- Buyers can place orders for agricultural products.
- Orders are organised according to the farmers supplying the products.
- Farmers can manage the status of received orders.
- Buyers can monitor their orders.

#### Responsive Interface
The platform is designed to provide a user-friendly experience across different screen sizes, including computers, tablets, and mobile devices.

### 3. Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js and Express.js
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT)
- **Development Tools:** Visual Studio Code and XAMPP (where applicable)

### 4. Expected Benefits

- Connects farmers directly with potential buyers.
- Makes agricultural products easier to discover.
- Simplifies product and order management.
- Reduces the difficulty of finding markets for farm produce.
- Encourages the use of digital technology in agriculture.

### 5. Conclusion

FarmConnect provides a digital solution to some of the challenges associated with traditional agricultural trading. By bringing farmers and buyers together on one platform, it creates an easier way to advertise, discover, and purchase agricultural products.

The project demonstrates how web technologies can be applied to improve agricultural commerce.
